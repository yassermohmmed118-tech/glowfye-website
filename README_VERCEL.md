# Deploy to Vercel

## الطريقة السريعة (Drag & Drop)
1. اذهب إلى https://vercel.com/new
2. اختر "Browse" واسحب مجلد vercel-deploy كاملاً
3. اضغط Deploy - سينتهي في 30 ثانية

## الطريقة بـ Vercel CLI
```bash
npm i -g vercel
vercel --prod
```

## الطريقة بـ GitHub
1. ارفع هذا المجلد لـ GitHub repo
2. في Vercel اختر Import from GitHub

الموقع Static 100% ولا يحتاج build.
